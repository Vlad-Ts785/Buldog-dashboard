# План: визуальный стандарт ЯРД Hub ("ГОСТ") + шейдерный акцент на канбане

**Дата:** 2026-08-27
**Автор:** Клод (по итогам сессии с Владом)
**Статус:** черновик

## Цель

Зафиксировать единый визуальный/звуковой/тактильный стандарт ("ГОСТ"), чтобы каждая
следующая доработка интерфейса (дашборд, CRM, любой новый экран) автоматически была
согласована с остальными - шрифты, цвета, отступы, кривые анимации, звук - без того,
чтобы каждый раз изобретать заново. Затем - один точечный эксперимент: взять
понравившийся "уровень 5" канбана и добавить в него немного GPU/шейдерности (не
превращая обратно в стекло, которое Влад отверг).

## Контекст

27.08 в этой сессии был прогнан живой эксперимент "потрогай разницу" - пять уровней
одного и того же канбана (от топорного vanilla до эталонной доски) и отдельно панель
управления на уровне 5, обе собраны методом "4 параллельных ИИ-специалиста + один
оркестратор" (дизайн / моушн / звук / дата-виз или графика). Влад подтвердил: уровень 5
в обоих случаях - целевое качество ("более чем устраивает"), само направление (vanilla,
не React - см. `project_crm_ui_target_level.md` в памяти) закрыто как решённое.

Проблема, которую фиксирует этот план: каждый уровень 5 проектировался с нуля через
свежих агентов - токены цвета совпадали (общая дизайн-система YARD Hub уже была), но
моушн-кривые, звуковые принципы, паттерн карточки, паттерн строки "метрика-значение"
изобретались заново в каждом демо. Если так же начать реальный редизайн CRM/дашборда -
разные экраны разъедутся по ощущениям. Нужен один документ-эталон, откуда черпать.

Материал для извлечения стандарта уже есть и проверен вживую в двух артефактах сессии:
- "Канбан на ощупь" (5 уровней, drag&drop, звук, победная сцена)
- "ЯРД Пульс" (BI-панель уровня 5: bullet-чарты, спарклайн, вафля парка, тикеры)

Полные текстовые спеки всех 8 агентов (дизайн x2, моушн x2, звук x2, дата-виз, графика)
- в transcript этой сессии, не сохранены отдельными файлами - при выполнении Фазы 1
нужно поднять историю сессии, если она не в контексте.
