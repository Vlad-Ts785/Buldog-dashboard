# Ретро: мост «Задание → Партнёры» + единый стандарт госномера

**Дата:** 2026-09-24 17:10
**Длительность:** ~2,5 часа
**План:** `plans/2026-09-24-hired-to-partners-bridge.md`

## 1. Задача

Всё, что логист пишет о наёмнике в «Задании», само наполняет реестр «Партнёры». Госномер
везде только по стандарту («по-другому не вводится»). Влад: «как архитекторы, а не как
говностроители».

## 2. Как решал

Разведка по живой базе, до кода: 28 строк наёмников, 26 связаны со Справочником, реестр
пуст. Номера записаны кто как. Двое водителей уже есть в Справочниках. Мобильная форма
пишет компанию текстом без id. Разбор «как архитектор» с тремя вариантами, Влад выбрал А.
Правило госномера, признак «партнёрский человек» и мост лежат в одном модуле
`api/lib/partner-bridge.js`, к нему 11 тестов. Сервер решает, браузер (`files/gos-plate.js`)
только помогает; две копии правила сверены на 34 случаях. Деплой через `./deploy.sh`
(72/72). Сверщик по истории: пробный прогон, запись, повторный прогон дал 0 действий.

## 3. Решил?

- [x] Да, полностью. Одно честное «не проверено»: живая постановка наёмника через интерфейс
  логиста (это запись в боевую заявку). Тот же код прошёл через сверщик на всей истории.

## 4. Что можно было лучше

- Попутно нашёл свой же баг от 22.09: создание партнёрской техники с номером НАШЕЙ машины
  шло через `ON DUPLICATE KEY UPDATE fleet_scope='partner'` и молча перекрашивало наш тягач.
  Сценарий «ключ уже существует» надо было проверить сразу. Урок: у любого upsert по
  естественному ключу (госномер) спрашивать, чья это запись.
- 22.09 я проверял API самодельными токенами, а они накручивали визиты в журнал. Сегодня
  проверки шли только через `tests/as-user.js`, старую запись в памяти поправил.
- Тест «ev318177» был ошибкой в самом тесте: «v» не двойник «В». Двойники определяются
  по виду буквы, не по звучанию.

## 5. Как было / как стало

- **Было:** реестр «Партнёры» пустой. Госномера в заявках свободным текстом («КАМАЗ Т2642»
  в поле прицепа). Три форматтера определяли прицеп и тягач по длине строки и путали их.
- **Стало:** 7 тягачей, 2 прицепа, 8 водителей в реестре, дальше наполняется сам при каждой
  постановке наёмника. Номер при вводе сам получает пробелы, мусор сервер не принимает.
