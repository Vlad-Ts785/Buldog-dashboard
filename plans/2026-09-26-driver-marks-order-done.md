# «Выполнено» отмечает водитель (пилот - группа Длинномеры)

**Зачем.** Статус «Выполнено» выключен с 21.09 (логист ставил заранее), из-за этого 136 прошедших
заявок висят «подтверждёнными» - нельзя сверить с 1С, что закрыто. Влад 26.09: логисты «сегодня
нажмут, завтра нет», контролировать их - не выход; факт «сделано» знает водитель, а длинномерщики
уже получают задания в боте MAX «Логист длинномеры».

**Успех MVP:** водитель длинномера, принявший задание в боте, в день рейса нажимает «🏁 Выполнил» -
заявка на дашборде становится «Выполнено», в истории видно кто и когда. Если забыл - бот сам
спрашивает в 19:00, при «Ещё еду» - повторно утром в 9:00.

## Решения Влада (26.09)
- Вариант 2 из разбора: кнопка работает только с дня рейса + вечернее напоминание.
- 19:00 - вопрос «выполнено?»; «Ещё еду» -> повтор в 9:00 утра.
- Заявку закрывает водитель ОСНОВНОЙ машины (у заявки один основной исполнитель с 24.09).

## Что НЕ делаем в v1
- Ручная кнопка «Выполнено» на сайте остаётся выключенной (закрывает только водитель).
- Наёмники и другие группы (тралы) - без закрытия, пока не подключены к боту.
- Проверка по GPS (Омникомм: доезжала ли машина до выгрузки) - этап 2, как контроль нажатия.
- Сверка с 1С - после недели данных, отдельным отчётом.

## Фаза 1 - MVP
- [ ] Схема: `plan_order_executors` + `driver_done_at`, `driver_done_ask_at`, `driver_done_asks`.
- [ ] Бот: после «Принял» - кнопка «🏁 Выполнил»; нажатие раньше дня рейса - вежливый отказ
      («отметить можно с дд.мм»); отметка -> `driver_bot_status='done'`, у основного исполнителя -
      заявка `done` + строка истории «Водитель … (бот)»; 5 минут - кнопка «↩ Ошибся».
- [ ] Вопрос «выполнено?»: `POST /api/logist_long/ask_done` (SERVER_KEY, `mode=evening|morning`,
      `dry=1`): вечер - принятые и не отмеченные с концом рейса сегодня (`delivery_date`, иначе
      `service_date`); утро - то же за 1-2 прошлых дня, не больше 3 вопросов на задание.
- [ ] cron через `run-job.js` (19:00 и 09:00 МСК) + строки в `JOBS` сторожа.
- [ ] Логист на сайте может вернуть «Выполнено» -> «Подтверждена» (ошибся водитель).
- [ ] Проверка на тестовой копии (staging): нажатия через вебхук, даты, отмена, повтор.

4 вопроса: решает (закрытие без логиста) · не код ради кода (кнопка + 1 вопрос в день) · не
усложняет (без GPS/1С) · выкинуто: ручная кнопка, наёмники, сверка.

## Фаза 2 - рост (не для v1)
- GPS-контроль нажатия: «Выполнил», а машина к выгрузке не подъезжала -> пометка логисту.
- Отчёт «закрыто водителем vs закрыто в 1С».
- Подключение других групп (тралы) к боту - та же кнопка.
