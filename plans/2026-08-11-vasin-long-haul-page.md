# План: личная страница логиста-длинномерщика (Васин Максим)

**Дата:** 2026-08-11
**Автор:** Клод
**Статус:** реализовано, ждёт деплоя

## Цель

Отдельная (не наёмная) личная страница для Васина - у него принципиально другая роль, чем у
Прус-Роскошного/Сильчева/Кана/Махуры/Сурковой: не брокер найма (500₽/заказ + 8% маржи), а
2.5% от ВП ВСЕХ длинномеров компании (собственный парк, формула `calcVasin`, см.
[[project_salary_rules]]). Нужна информационная панель по направлению "длинномеры" целиком:
прибыль по каждой машине, воронка путевых листов, несданные путевые по водителям, все сделки
по длинномерам (независимо от исполнителя), зарплата, выбор периода.

## Контекст

Продолжение серии личных страниц (см. три плана от 2026-08-10/11 в этой же папке). Влад,
дословно: "нужна вся информация, которая может быть полезна по длинномерам... валовая прибыль
по каждой машине как во вкладке Водители/Техника... воронка по путевым листам... список кто из
водителей не сдал... полностью информационная панель... внизу зарплата... выбор периода...
видеть все сделки по длинномерам независимо от того, только он ли выполнял заказ".

Технически это стык ДВУХ разных источников данных, которые раньше никогда не смешивались на
одной странице:
1. `aggregateOrdersRows` (Заказы_данные) - заказы/воронка/сделки.
2. `aggregateFinHistoryForRange` (Данные_1С_история/История_финансов + Штатка) - прибыль по
   машине, тот же источник, что вкладка "Техника".

`profit_long` (ВП длинномеров компании, нужен для зарплаты) для ТЕКУЩЕГО месяца берётся из
`getSummaryData()` (живой лист Нормализованные_данные), для ПРОШЛОГО - из
`getGrossProfitForPeriod()` (История_финансов) - те же источники, что уже использует admin
для панели/периода, просто раньше не были доступны роли `logist`.

## Реализация

### Бэкенд
- `aggregateOrdersRows`: `longFunnel` (4 стадии, company-wide, только `equip==='Длинномер'`,
  та же классификация skipToComplete/hw/pst/hr, что и общая воронка); `driverMap` расширен
  полями `orders_long`/`no_waybill_long` -> `by_driver_no_waybill_long`; `allLongDeals` - КАЖДАЯ
  строка с `equip==='Длинномер'` (свой парк + наём вместе), обрезка 500, сортировка по дате.
- `getLongHaulDetail_(ss, period)` - объединяет: `aggregateFinHistoryForRange` (фильтр
  Борт/длинномер, тот же предикат, что `getFleetStatus`/`isLongVehicle` на фронте) + новые поля
  из `aggregateOrdersRows` + `profit_long` (getSummaryData для текущего/getGrossProfitForPeriod
  для прошлого).
- `action=long_haul_detail&period=YYYY-MM` (period пустой = текущий месяц) - доступен
  `admin` и `logist` (любому, не только Васину - как и "Общие сделки" у Прус, доступ по
  направлению, не по фамилии).

### Фронтенд
- Диспетчер `renderMyPage()`: если выбранный `current` - Васин (логист, фамилия "васин"),
  роутит в новую `renderMyPageVasin()` вместо `renderMyPageLogist()`.
- `renderMyPageVasin()` - собственный жизненный цикл загрузки (не завязан на
  `myPagePeriodCache`/`D.orders`-подмену, т.к. источник другой): свой кэш `vasinDetailCache`,
  ключ - период; переключатель периода переиспользует ту же пару кнопок/переменную
  `myPagePeriod`/`setMyPagePeriod`, но `setMyPagePeriod` для Васина НЕ делает
  orders_period/my_page_period запрос (это чужой формат данных) - только выставляет
  `myPagePeriod` и даёт `renderMyPageVasin` подгрузить свои данные лениво.
- Блоки: KPI-шапка (заказы/выручка/ВП длинномеров/документы), таблица "ВП по каждой машине"
  (те же колонки, что "Техника"), воронка путевых листов, "Не сдали путевые" по водителям,
  "Все сделки по длинномерам" (с колонкой "Свой/Наём"), "Расчёт зарплаты" (`calcVasin`).
- `positionLabel()`: Васин -> "Логист (длинномеры)".
- Убрать мёртвый код `isVasin`-ветку из `renderMyPageLogist` (Васин больше туда не попадает).

## Критерии готовности

- [ ] Таблица по машинам сходится с "Техника" (тот же источник, отфильтрован по длинномерам).
- [ ] Зарплата Васина видна и за текущий, и за прошлый месяц (раньше в урезанной роли
      `logist` не работало вообще - `D.summary` не приходил).
- [ ] "Все сделки" показывают и свой парк, и наём, независимо от исполнителя.
- [ ] Регрессия: страница Прус-Роскошного/остальных наёмных логистов не задета.

## Риски

- `action=long_haul_detail` доступен любому `logist`-аккаунту (не только Васину) - осознанно,
  по аналогии с "Общие сделки" (риск уже принят и подтверждён Владом в прошлой итерации).
