# «Умный звонок»: полноценный плеер записи + расшифровка + автозаполнение брифа сделки

## Зачем

Влад (08.09, после того как увидел кнопку «Прослушать»): нужен нормальный плеер с
перемоткой (как у Mango/почти у любого плеера записи), и расшифровка звонка с сутью
разговора + автозаполнение карточки сделки (груз/откуда/куда), «как в Битриксе»
(https://helpdesk.bitrix24.ru/open/27105168/ - справка Битрикса про распознавание речи).

**Как выглядит успех MVP:**
1. У записи - реальный плеер: играть/пауза, шкала с перемоткой (клик/тащить), время
   тек./общее - не просто одна кнопка «Прослушать»/«Пауза».
2. Кнопка «Расшифровать» рядом - показывает текст разговора + короткую суть (2-3
   предложения) под записью.
3. Если в разговоре прозвучало «что везём»/«откуда»/«куда» - поля брифа сделки
   заполняются САМИ, той же меткой `brief_source='auto'`, что уже есть у автоизвлечения из
   переписки - НЕ затирая то, что менеджер ввёл вручную.

## Что НЕ делаем в v1

- Не транскрибируем ВСЕ звонки автоматически фоном - платно (кредиты kie.ai) и не нужно,
  пока менеджер сам не попросил («Расшифровать» - по клику, не по факту звонка).
- Не делаем разделение по говорящим (diarization - «кто что сказал») - для сути разговора
  и извлечения брифа хватает сплошного текста; можно добавить позже, если понадобится.
- Не трогаем распознавание тональности/оценку качества звонка (у Битрикса это тоже есть) -
  отдельная фича, не запрошена.

### 1.3 Суть разговора + автозаполнение брифа
- [ ] Один вызов уже работающего `callKieGpt5_` (codex/v1/responses, `gpt-5.6-luna`) с

- [ ] `applyCargoBriefToDeal_(dealId, brief)` - **тот же существующий вызов**, что и для

- [ ] Показ сути + текста расшифровки в таймлайне рядом со звонком; если бриф применился -

### Доп. правка (09.09, тот же день) - диаризация (разделение по говорящим)

Влад прислал гайд nexara.ru/phone-call - хочет не сплошной текст, а разбивку
"Менеджер: ... / Клиент: ...". Сделано:

- Server: `task=diarize`, `num_speakers=2`, `model=nexara-ru` (точнее на русском).
  **Живой тест 09.09 - важная находка:** `roles` ПРОСТЫМ массивом имён
