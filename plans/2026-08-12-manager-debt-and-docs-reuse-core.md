# План: ДЗ и Воронка документов на странице менеджера - переиспользовать общее ядро

**Дата:** 2026-08-12
**Автор:** Клод
**Статус:** реализовано, ждёт деплоя

## Цель

Влад (по скринам global ДЗ и "Проблемные заказы"): не изобретать заново - вкладки
"Дебиторская задолженность" и "Воронка документов" на личной странице менеджера должны быть
в ТОМ ЖЕ формате, что уже есть на дашборде, и брать данные из одного источника с ним.

## Реализация

### ДЗ-вкладка
- Убран текстовый инпут "Мин. сумма долга" - заменён двойным слайдером диапазона
  (`.range-slider`, новый CSS-компонент, два `input[type=range]` внахлёст + заполненная
  полоса между ними, без единого текстового поля).
- Разворачивание строки контрагента по клику - показывает список документов через
  `buildDebtDocsHtml_` (та же самая функция, что уже открывает строку в global ДЗ) - даты,
  юрлицо, номер реализации, сумма, сверка "Итого/Аванс/Открыто по факту".
- Цвет просрочки (`ageCls`, тот же светофор, что в global ДЗ: >90 красный, >30 жёлтый,
  иначе зелёный) и строка "от какого юрлица работаем" (`byOrg`, тот же формат
  "— Бульдог: 452 500 ₽").
- Статус - только просмотр текстом, без `<select>` для смены (Влад: "без возможности менять,
  только статус видеть").

### Воронка документов
- Компактная сводка (сегментированная полоса + счётчики по стадиям) оставлена сверху.
- Ниже добавлена детальная таблица - тот же формат, что "Обзор заказов → Проблемные заказы":
  вкладки-фильтры Все/Нет путёвки/Не проведён/Нет реализации + таблица с теми же 9 колонками
  (Номер/Дата/Декада/Клиент/Менеджер/Водитель-наёмник/Сумма/Оплата/Статус).
- Один источник строки - `problemOrderRowHtml_(p)` вынесена из `filterProblems()` (global
  страница) в отдельную функцию, переиспользуется ОБОИМИ местами - не два похожих шаблона,
  а один.

### Бэкенд
- `buildManagerView_` прикладывает `orders.problem_orders`, отфильтрованный на этого
  менеджера (приватность - другие менеджеры не видны роли `manager`); admin-предпросмотр
  дополнительно фильтрует на фронте (там company-wide список).

## Проверка

- Слайдер диапазона - без текстового ввода, границы двигаются, фильтрует таблицу.
- Разворачивание строки - документы в точности как на скрине Влада (даты/юрлицо/реализация/
  суммы + сверка).
- Воронка документов - таблица с фильтрами по статусу, тот же формат, что "Проблемные
  заказы", отфильтровано на менеджера.
- Регрессия: global "Проблемные заказы" (после рефакторинга на `problemOrderRowHtml_`),
  Прус/Васин - не задеты.
