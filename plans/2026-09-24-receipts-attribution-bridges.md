# Чьё поступление - мостики между базами

**Дата:** 24.09.2026. **Запрос Влада (23.09):** «у нас есть все возможности лучше определять,
чьи поступления. Мы же знаем, например, что со Стрелой работает Савиток».

## Правило (решение Влада 24.09)

Поступление принадлежит тому, **кто вёл оплаченный документ** (а). Где документ определить
нельзя - текущему владельцу клиента (б); уволенных (`sprav_people.employment_status='fired'`)
на шагах (б) пропускаем, честное «не определён» лучше неверной фамилии. Деньги от поставщиков
(метка 1С «(поставщик ...)») и «(НАШ)» - не выручка, отделяются как внутригрупповые.

## Что было

Один мостик: название плательщика из СМС -> последняя сделка в 1С. С 28.08 по 23.09:
287 поступлений, опознано 67% штук / 70% денег, без менеджера ~14.6 млн. Причины:
1. В 1С менеджеры дописывают метку в название клиента («СТРЕЛА ООО Савиток»), ключ из банка
   («СТРЕЛА») с ним не совпадал.
2. Пакетные платежи «по N документам от ...» теряли плательщика целиком (23 шт., 4.77 млн).
3. Порядок слов: банк «ТК ВЕЛОКС», 1С «ВЕЛОКС ТК».
4. Менеджер документа в дебиторке терялся при сохранении (1С его отдаёт).

## Фаза 1-2 - сделано 24.09 (VPS `1649b00`, `1a26a64`)

- [x] Разбор пакетных платежей в `parseBankSms_`, добор плательщика для старых строк.
- [x] `api/lib/receipt-attribution.js` - цепочка мостиков по порядку:
  свои (Справочники) -> метки поставщик/НАШ -> **документ в дебиторке по сумме** (а) ->
  владелец по дебиторке -> 1С-поступление той же даты и суммы -> «Задание» v2 -> последняя сделка.
- [x] Штамп в `bank_operations` (`kind`, `match_source`, `match_doc`) в момент прихода СМС:
  оплаченный документ виден только пока он открыт в дебиторке, потом 1С его закрывает.
  Сверка «по документу» - только для сегодняшних платежей и документов не новее платежа
  (для старого платежа открытый документ на ту же сумму = признак, что платёж его НЕ оплатил).
- [x] `debt-calc.js`: менеджер документа сохраняется в `unpaid_docs`.
- [x] `/api/receipts`: поставщики/НАШ вне сумм; менеджер 1С-поступления = менеджер
  оплаченного документа, если СМС опознала его по документу.
- [x] Строки до 24.09 менеджера не меняют (`match_source='legacy'` - владелец на момент
  платежа), меняется только классификация свои/поставщики.
- [x] Сайт: в ленте «своя компания»/«поставщик» вместо менеджера, подсказка «как определён»;
  карточка менеджера и «фанфары» не считают своих и поставщиков.

**Итог:** без менеджера осталось 23 поступления / 2.86 млн (было 95 / ~14.6 млн). Попутно:
~3.7 млн переводов от ТЕХНО ПАРК были записаны на логистов (Сильчев/Кан/Махура) - теперь свои.
