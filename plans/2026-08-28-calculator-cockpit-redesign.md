# Калькулятор 2.0 - кокпит «Табло рейса»

Статус: в работе (2026-08-28). Утверждено Владом на превью
(https://claude.ai/code/artifact/891bcf55-6dc7-4281-97b0-cdeed2aebb9d) со словами
«сделай именно так, как ты показал, без корректировок» - превью = контракт.

## Откуда взялся дизайн

Три агента (запущены Владом 28.08): критик-UX («вариант 1 - интерфейс КП, натянутый
на телефонный звонок; мерило - секунды до первой названной цифры»), дизайнер-визионер
(концепт «Табло рейса» из трёх кандидатов), графист-датавиз (лента маршрута,
стековая полоса цены, габаритные ворота, bullet массы). Полные отчёты - в сессии.

## Что меняется (вкладка Калькулятор, files/index.html)

Кокпит без скролла: маршрутная строка кольцом (База → Погрузка → Выгрузка → База,
км под адресами кликабельны = ручной ввод равноправен) + чипы частых маршрутов;
карта Leaflet + SVG-лента маршрута (штрих = порожний, сплошная синяя = с грузом,
дуга ×N = круговые рейсы); карточка груза (крупная масса + чип «авто», Д/Ш/В,
техника, bullet массы против предела, габаритные ворота 2,55×4,00, строка-вердикт);
табло цены сплит-флэп с 4 состояниями (пусто / вилка по массе / готова + дельта-чип /
СОГЛАСУЙТЕ при >120 т), стековая полоса + легенда-строки с % долями, кнопки
Сохранить / КП / Копировать фразу; история в drawer справа (₽/км, сверка с медианой,
мини-скаттер с живой точкой текущего расчёта).

Линии на карте - те же коды, что на ленте: плечо с грузом сплошная --blue 4px,
порожние плечи штриховые --blue 45% 2.5px; база - полый квадрат, точки - светлые круги.

## Правила переноса

1. **Формулы не трогаем ни на цифру** - calc() меняется только в блоке ВЫВОДА:
   вместо записи строк в clc-bd* собирает объект Clc._last с числами и зовёт
   renderBoard_(). Ранний return (нет маршрута) - renderBoard state empty/range.
2. Все id входов движка сохраняются (clc-weight, clc-len/wid/hei, clc-vehType,
   clc-faymonCat, clc-loopCount, clc-manualKm, clc-mkm1/2/3, clc-loadAddr/unloadAddr,
   clc-map, clc-techSearch/techList/techCat...). Тип груза (clc-cargoType) становится
   скрытым - выставляется автодетектом из массы/габаритов (порог как в selTech:
   w>20 || l>13.6 || d>2.55 || h>4), ручного выбора в превью нет.
3. Категория Faymonville - авто по массе (syncFaymonCat уже есть), подпись категории
   показывается в option самого селекта техники; отдельный селект категории скрыт.
4. Опции корыта (clc-koritoGrp/ExtGrp) и зона сопровождения (escZoneGrp) остаются -
   появляются условно под селектом техники, как и раньше (vhCh/calc управляют).
5. Вилка цены (состояние range): min = смена по массе/технике, max = смена +
   типовой дальний 700 км (700×kmRate + 900×emptyRate), подпись «вилка по массе
   и технике». Это ориентир до маршрута, НЕ меняет методику точного расчёта.
6. toast() движка становится прокси на единый p2Toast (ГОСТ, единый канал),
   все эмодзи из сообщений и вывода вычищаются (запрет ГОСТа).
7. Кнопка «По модели» открывает поповер с существующим поиском по базе техники
   (те же clc-techSearch/clc-techList/clc-techCat - функционал не теряется).
8. Чипы частых маршрутов - топ направлений из серверной истории (calc_history);
   клик подставляет адреса + км прошлого расчёта (ручной режим) - цена сразу.
9. «Копировать фразу» - в буфер: «Перевозка: <откуда> - <куда>, <техника>: <сумма>
   с НДС».

## Не переносится/остаётся

- Генерация КП (genKP) - без изменений.
- Серверное сохранение/история (calc_save/calc_history) - без изменений протокола,
  меняется только отрисовка списка (drawer).
- Leaflet/OSRM/Nominatim - без изменений, только стили линий и маркеров.

## Итерация 2 (28.08, вечер, фидбек Влада по живой версии)

- Переполнение на ноутбуках: все grid-колонки переведены на minmax(0,...) - инпуты
  больше не распирают строку; длинные тексты легенды переносятся (кнопки не выезжают).
- Карта и груз всегда одной высоты (stretch, карта flex-растёт).
- Ручной ввод км УБРАН из UI (скрытый механизм жив для повтора из истории).
  Вместо него - чипы-базы: «База Домодедово» слева/справа нажаты по умолчанию,
  клик отжимает - порожнее плечо исключается из расчёта.
- База: точные координаты Промышленная 37 (55.467403, 37.778261).
- Ворота: сечение от ЗЕМЛИ (платформа: тралы/корыто 0,5, длинномер/панелевоз 0,9,
  Faymonville 1,0 м); выступы целиком янтарные (синие линии не проходят сквозь);
  подпись фактической ширины - по центру над пунктиром, «2,55 м» ниже.
- НОВЫЕ СТОПЫ (согласуйте с руководителем): ширина > 4,5 м; высота с платформой > 4,8 м.
- МАШИНА ПРИКРЫТИЯ в формуле: при ширине > 3,5 м или длине > 19 м;
  21 000 ₽ смена + 60 ₽/км с грузом (каждую ходку). Отдельная строка и сегмент.
- ×2 СВЕРХГАБАРИТА (>17 м / >4 м / >4,5 м) - вместо прежнего «Кат. 3 -
  индивидуально»: применяется к СМЕНЕ и КМ С ГРУЗОМ; порожние, сопровождение,
  прикрытие - без ×2. Категория сопровождения теперь только по массе.
