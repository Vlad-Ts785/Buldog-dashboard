прошёл Ревизора (5 правок) и Око Саурона (пре-мортем, 3 инварианта + 4 правки до старта).

## ТРИ ИНВАРИАНТА (Око Саурона - нарушать нельзя ни на одном шаге)

1. **"Этап закрыт = старый путь ВЫКЛЮЧЕН"** (не "новый заработал"). И с сегодняшнего дня
   в Apps Script не добавляется НИЧЕГО нового - только фолбэки и сторож. Иначе - вечный
   гибрид: два мира, каждая правка в двух копиях, навсегда.
2. **"Ни одной строки миграции в server.js до git на VPS"** - П.1 повышен до блокера
   (затирание кода параллельными сессиями случилось дважды 01.09).
3. **"У Влада всегда две двери и одно зеркало":** break-glass admin-токен в .env с
   инструкцией на случай сломанного входа + Apps Script-логин живёт весь переходный год
   как вторая дверь + read-only Google-зеркало 3-4 ключевых таблиц MySQL (cron раз в
   день) - привычный Владу аудит глазами сохраняется.

## КРИТИЧЕСКОЕ ОТКРЫТИЕ РЕВИЗИИ (правит текущую систему, не только план)

**Sheets-фолбэк для Заказов/ДЗ/Поступлений уже МЁРТВ.** Email-рассылки этих трёх отчётов
остановлены 17-19.08 (подтверждено Gmail-диагностикой 01.09) - листы заморожены на
середине августа. "Тихий фолбэк на лист" при падении сервера молча покажет цифры
двухнедельной давности как живые. Реальная страховка этих потоков - уже НЕ Sheets, а
бэкапы VPS и его uptime. Фикс (вне очереди, до любых этапов): freshness-проверка в
фолбэк-ветках Apps Script - лист старше N часов -> флаг stale_fallback -> плашка на
фронте "данные от [дата], сервер недоступен".

## Зачем (решение Влада, 01.09.2026)

"Это ещё раз подтверждает что нам нужно уходить от скрипта". Три подтверждения за один день:
1. Лимит платформы Google - 200 версий проекта - остановил деплои посреди рабочего дня.
2. Трёхчасовой кэш Apps Script (`Кэш_главной_страницы`) сделал невозможным "мгновенно"
   для простой операции (скрыть машину) - пришлось городить живой фильтр поверх кэша.
3. Apps Script HEAD не под git - две параллельные сессии дважды затёрли код друг друга.

Плюс стратегия и так утверждена с 2026-08-18 ([[project_server_migration_strategy]]).

## Фактическое состояние (сводка 4 отчётов разведки, 01.09.2026)

**Уже на сервере (Apps Script - только прокси/фолбэк):** заказы+зарплаты+воронка
(`orders_computed`), ДЗ целиком, поступления, деньги парка (`park_history`/`park_summary`),
водитель по машине, department-исключения, калькулятор+нумерация КП (100%, фолбэка нет),
статусы ДЗ (двойная запись). Страницы целиком на сервере: CRM, Справочники, Планировка,
Навигация, База клиентов, банковские СМС.

**Держит на скрипте:**
- Выдача session_token и роли (вход) - сервер умеет проверять токен, но не выдавать.
- Главный payload (`D`) - питает Панель/Продажи/Зарплаты/Технику/ДЗ + `D.vehicles` для
  Планировки и Навигации.
- Штатка (тип/статус/марка/план машины) - корень: пока она в Sheets, нужен и кэш, и
  email-канал "Отчет парк".
- Динамика (`vehicle_history`), Глобальная статистика (`global_stats`) - 100% скрипт.
- Персональные срезы: `my_page_period`, `vehicles_period`, `own_tral_prev_month`,
  `manager_lost_customers`, `manager_profile`.
- ИИ-задачи (kie.ai + кэш в листе), Telegram-отчёт, Bitrix-маркетинг.
- "План задание" - CRUD во внешней Google Таблице логистов (самый объёмный кусок).
- Планы менеджеров (`Планы_менеджеров`) - Влад вводит руками, накладываются поверх ЛЮБОГО
  расчёта, UI ввода на сервере нет.

**Инфраструктурные ограничения VPS:** 1 ГБ RAM (OOM уже был), диск 82% занят, телематика
+20К точек/день без ротации, код не под git.
