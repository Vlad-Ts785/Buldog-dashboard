# Переключатель тёмной/светлой темы - весь дашборд

**Создан:** 2026-08-29 по запросу Влада: «переключение на светлую тему... чтобы вся
биосистема наша могла переключаться, то есть пользователь у себя мог выбрать тёмную
или светлую тему». Способ - ручной переключатель (выбор Влада через опрос), НЕ
системная тема. Референс - превью «Планировка ЯРД» (artifact 2e19a2a1), где паттерн
уже отработан и одобрен Владом.

**Статус:** план готов, реализация не начата.

**Исследование:** 2 агента на Fable 5 (полный аудит цветов + архитектура механизма),
29.08. Ключевые цифры: ~297 hex + ~206 rgba() в files/index.html, из них ~65% -
механическая токенизация; 11 графиков Chart.js со 100% захардкоженными цветами;
~26 render-функций красят инлайн; инфраструктуры темы в коде НЕТ вообще (0 вхождений
data-theme/prefers-color-scheme/getComputedStyle).

## Паттерн (перенесён из «Планировки», НЕ копированием - в репо того файла нет)

- `data-theme="light"` на `<html>`; тёмная = отсутствие атрибута (дефолт).
- `:root[data-theme="light"]` переопределяет ТОЛЬКО поверхностные токены.
  Палитра из референса (уже одобрена Владом на «Планировке»):
  `--bg:#f2f4f7; --bg2:#ffffff; --bg3:#eceff3; --bg4:#e1e5eb;`
  `--border:rgba(20,26,38,0.10); --border-strong:rgba(20,26,38,0.20);`
  `--text:#1b1f27; --muted:#5c6474;`
- Акцентные --green/--red/--amber/--blue/--purple НЕ переопределяются.
- Новые парные токены `--tint-*` - приглушённые надписи ПО ЦВЕТУ поверх
  полупрозрачных заливок (на тёмном - светлый тон hue, на светлом - тёмный тон):
  тёмная: `--tint-green:#8fd9bf; --tint-blue:#a9cdf2; --tint-amber:#f0c98a;
  --tint-purple:#c1bcf0; --tint-red:#eeadac;`
  светлая: `--tint-green:#0f6a4c; --tint-blue:#1c5ea8; --tint-amber:#8a5a12;
  --tint-purple:#584fb0; --tint-red:#a23b3a;`
  Ими заменяются осветлённые одноразовые hex (#4fd4a3/#f07b7a/#f5be6a/#e0954a/#7db9ee
  в CSS 272-287 и их дубли в JS).
- localStorage ключ `yardhub_theme` (конвенция yardhub_sound_on), try/catch на
  чтение/запись. При logout НЕ чистится (clearAuthTokens_ трогает только токены -
  проверено, менять не надо).
- Кнопка «Тема: тёмная/светлая» в футере сайдбара - точная копия механики звукового
  тумблера (toggleUiSound 15108, span-лейбл, uiSounds.toggle() на клик). Футер виден
  и в мобильном меню.
- Против FOUC - синхронный однострочник в <head> ПОСЛЕ мет (строка ~10), ДО
  <style>: `try{if(localStorage.getItem('yardhub_theme')==='light')
  document.documentElement.setAttribute('data-theme','light')}catch(e){}`.

## applyTheme() - взаимодействие с ленивым рендером (Этап 2 плана загрузки)

1. Выставить/снять атрибут на html, обновить лейбл кнопки, записать localStorage.
2. Пометить ВСЕ dirtyGroups_ = true; перерисовать группу активной страницы
   (renderGroup_), а для ролей manager/logist/предпросмотра - renderMyPage() (у них
   render() выходит рано).
3. Активная страница ВНЕ групп (dynamics/clients/crm/global-stats/order-plan/
   calculator/ryschanow-salary/commercial-head-*) - повторить её ветку из showPage
   (load*Data из кеша перерисовывает без refetch; crm перезагружает - приемлемо).
4. НЕ через loadData() - lastAppliedHash_ заблокирует, и сеть тут не нужна.
5. Открытая модалка техники (vcardChart) остаётся старой до переоткрытия - известное
   ограничение, лечится закрытием.

## Этапы

### Этап 1. Инфраструктура + палитра (самодостаточен, после него тема РАБОТАЕТ ~80%)
- :root[data-theme="light"] с палитрой выше; объявить --border-strong в базовом
  :root (сейчас его НЕТ - везде работает только fallback в var()).
- Ранний скрипт FOUC, кнопка в футере, applyTheme()/toggleTheme()/loadTheme().
- Большинство UI уже на токенах - переключение сразу даст рабочую светлую тему с
  известными шероховатостями (этапы 2-3).

### Этап 2. Механическая токенизация CSS (~70 мест в <style>)
- rgba(255,255,255,.04-.12) разделители -> var(--border) / новый --hairline.
- rgba(255,255,255,.16) -> var(--border-strong).
- Hover-полуступень #191920 (419/425/867) -> новый токен --bg-hover
  (тёмная #191920 / светлая #eaeef3 - из референса --row-hover).
- Чёрные тени попапов/тостов -> токен --shadow-pop (на светлом тени слабее не
  нужны - наоборот виднее, оставить те же значения, вынести в токен для будущего).
- Осветлённые акценты 272-287 -> --tint-*.
- Белые тики (clc2-bullet-tick, mp-dual__tick...) -> var(--text) или --tint.
- Курсорный свет rgba(55,138,221,.07): на светлой теме приглушить -
  [data-theme="light"] вариант rgba(55,138,221,.05) ЛИБО скрыть; решение - показать
  Владу оба, дефолт - приглушённый.
- Логотип на лоадере (filter:invert под тёмный фон, 540) - на светлой теме убрать
  инверсию: [data-theme="light"] .loading-logo{filter:none}.
- Шиммер #fff (541) -> на светлой теме тёмный блик.

### Этап 3. JS-цвета (перерисовка уже решает, надо только токенизировать строки)
- Инлайн style в шаблонах: hex-литералы -> 'var(--green)' и т.п. (CSS-переменные
  в inline style работают). ~107 строк, механически, НО частями по страницам с
  проверкой глазами каждой.
- Дублирующие палитры-константы (PAGE_COL, COL x2, dept-конфиги, debtOrgColors,
  segColors) - акцентные цвета, тема их не трогает, НЕ переделывать сейчас
  (отдельный рефакторинг, не смешивать).
- Chart.js: хелпер chartTheme_() -> getComputedStyle(document.documentElement)
  .getPropertyValue(...) для ticks/grid/legend/tooltip (сейчас #888780/
  rgba(255,255,255,.04)/#e8e6df/#1a1a22 запечены в 11 графиках). Датасеты
  (акценты) не трогать. Пересоздание при смене темы - бесплатно через
  dirty+renderGroup_.
- Спарклайн ДЗ: кольцо stroke="#17171d" (7897) -> var(--bg2); muted #8b8980
  (7889) -> var(--muted).
- Кнопки btn.style.color='#000'/'#fff' (13089-13095 и др.) - проверить контраст
  на светлой, скорее всего не трогать (фон кнопки акцентный).

### Этап 4. Мелочи и дизайн-решения (после того как Влад пощупает 1-3)
- meta theme-color: менять из applyTheme (тёмная #1D9E75 оставить / светлая тоже
  зелёная - вкладка браузера).
- Конфетти/салют #e8e6df частицы - на светлом невидимы; заменить на var(--text)

- Google Sign-In кнопка theme:'filled_black' - видна только на экране логина ДО
  загрузки темы пользователя; оставить как есть (логин-экран тёмный всегда) ЛИБО
  красить по localStorage - решить с Владом.
- manifest.json background_color - статичен, сплэш PWA останется тёмным
  (ограничение платформы, зафиксировать).
- examples/design-reference-*.html - НЕ трогать (ГОСТ: эталоны заморожены).

## Правило перехода
1 -> 2 -> 3 одной серией (иначе светлая тема выглядит сломанной), показ Владу,
4-5 - после его прогона. Деплой этапами с проверкой глазами на живом (переключить
туда-сюда на каждой странице - чек-лист приёмки ГОСТа прогонять в ОБЕИХ темах).

## Известные ограничения (зафиксированы, не баги)
- Открытые модалки/drawer'ы в момент переключения не перекрашивают запечённый
  инлайн - лечится переоткрытием.
- Сплэш PWA всегда тёмный (manifest статичен).
- Экран логина до первого входа - тёмный (тема хранится per-устройство).
- PDF-генератор КП (jsPDF) - всегда белый, темы не касается.
