# План: прогноз по каждой машине + задачи на день + убрать наём (страница Васина)

**Дата:** 2026-08-11
**Автор:** Клод
**Статус:** реализовано, ждёт деплоя

## Цель

Три доработки страницы Васина (см. серию планов `2026-08-1*-vasin-*`):
1. Прогноз выполнения ВП по КАЖДОЙ машине (не только общей шкалой) - по примеру вкладки
   "Водители" (план/факт/прогноз/оценка-действие).
2. Блок "Задачи на сегодня" между 4 KPI-карточками и таблицей машин - максимум 5 пунктов.
3. Убрать всё, что касается наёмной техники - у Васина только собственный парк.

## Реализация

- Переиспользован уже существующий `driverForecastStatus_(forecastPct)` (module scope, тот
  же, что уже красит статусы на "Водителях") - зелёный "Идёт по плану" / жёлтый "Добавить
  заказов" / оранжевый "Загрузить срочно" / красный "Простой — разобраться". Ничего нового не
  придумывалось - те же пороги и формулировки, что Влад уже видел на "Водителях".
- Таблица машин - новые колонки План ВП/Прогноз/Оценка, `paceRatio` - тот же, что уже считает
  общую шкалу плана сверху.
- "Задачи на сегодня" - генерируются на лету из тех же данных, что уже на странице (не новый
  запрос): (1) один пункт - топ-3 водителя без путевых по количеству несданных; (2) по одному
  пункту на машину со статусом "Загрузить срочно"/"Простой", худшие сначала, до заполнения
  лимита в 5 суммарно.
- Наём убран: KPI "Заказов"/"Выручка" теперь по `own_long_orders`/`own_long_amount` (новое
  поле в `aggregateOrdersRows` - выручка ТОЛЬКО собственного парка длинномеров, раньше такого
  разреза не было); блок сделок фильтрует `all_long_deals` по `!is_hired`, колонка "Тип"
  убрана (все строки теперь одного типа).

## Критерии готовности

- [x] Прогноз/статус по каждой машине, те же формулировки, что на "Водителях".
- [x] Задачи на сегодня - не больше 5, между KPI и таблицей машин.
- [x] Наём нигде не упоминается на странице Васина (KPI, сделки).
- [x] Проверено на синтетике: все 4 статуса (green/amber/orange/red), лимит 5 задач,
      сортировка задач по убыванию срочности, фильтр наёмных сделок.
- [x] Регрессия: Прус-Роскошный не задет.
