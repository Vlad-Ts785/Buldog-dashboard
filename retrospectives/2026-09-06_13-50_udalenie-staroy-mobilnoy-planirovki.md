# Ретро: удаление мёртвого кода старой мобильной Планировки из index.html

**Дата:** 2026-09-06 13:50
**Длительность:** ~60 минут
**План:** `plans/2026-09-05-mobile-planning-page.md` (пункт v11)

## 1. Задача

Аккуратно вырезать из `files/index.html` старый сжатый мобильный режим «Таблица»
Планировки (CSS/HTML/JS, ~700 строк), который с коммита `8d62cab` недостижим с
телефона (редирект на `plan-m.html` в `showPage()`), пометить раздел ГОСТа как
выведенный из эксплуатации, проверить, что десктоп работает как раньше.

## 2. Как решал

1. `git fetch` + сверка: HEAD совпадал с `origin/main` на старте, к моменту push
   `origin/main` уехал на один коммит (`62f4e12`, plan-m.html + план) - rebase,
   один конфликтный хунк в плане (обе стороны дописали «v10»), слил вручную, мой
   пункт стал v11.
2. Инвентарь одним `grep -n` по всем именам (`lp-mobile`, `lp-m-`, `lpM*`,
   `IS_TOUCH_`, `touchstart`…) - сразу видно, что `lpGosShort_` нигде больше не
   используется, а `IS_TOUCH_`-гейты в pointerdown десктопа надо оставить.
3. Патч - Node-скрипт по номерам строк с проверкой каждой границы (`assertStarts`)
   ДО первой записи, удаление снизу вверх, latin1 для байт-в-байт CRLF. Три первых
   запуска упали на сдвиге в одну строку (номера были из ранее прочитанных
   фрагментов) - файл не пострадал ни разу, потому что скрипт падает до записи.
4. Синтаксис: свой `check_scripts.js` (vm.Script на каждый `<script>`) - базлайн
   2 ложных срабатывания в HEAD, столько же после патча.
5. Живая проверка в Browser pane: порт 3000 занят другим чатом - добавил в
   `.claude/launch.json` (не в git) конфиг `dashboard-wt` на 3017. Логина нет -
   подставил тестовый парк из 3 машин через bare `D` и вызвал `showPage`
   (top-level `let D` доступен по имени из javascript_tool). Прогнал создание
   протяжкой, драг на другую строку, растяжку, ПКМ, масштаб, фильтры; A/B с копией
   HEAD по `scrollLeft` после смены масштаба - идентично. Эмуляция телефона
   (`resize_window mobile` даёт `pointer:coarse`+`hover:none`) - редирект на plan-m.
6. ГОСТ: баннер «ВЫВЕДЕНО ИЗ ЭКСПЛУАТАЦИИ» над старым подразделом, история 2.4.

## 3. Решил?

- [x] Да, полностью

## 4. Что можно было лучше

- Номера строк для патч-скрипта брать `grep -n` по маркерам непосредственно перед
  запуском, а не переписывать из ранее прочитанных кусков - сэкономило бы три
  холостых запуска.
- В Browser pane координаты кликов - в кадре скриншота (800x491 при вьюпорте
  1400x860), не в CSS-пикселях: первая протяжка ушла за край кадра.

## 5. Как было / как стало

- **Было:** в `index.html` лежали ~650 строк мобильного режима, до которых пользователь
  не мог добраться; при правках десктопной ленты приходилось обходить `lp-mobile`-ветки
  (короткий госномер, `lpMSync_` в `renderRowsInner_`, toggle классов в `initLP`).
- **Стало:** десктопная Планировка - единственный режим внутри `index.html`, телефон
  всегда на `plan-m.html`; `IS_TOUCH_` остался только как страховочный гейт.
