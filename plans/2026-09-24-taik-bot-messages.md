## Как это работает

**Одно сообщение на платёж.** Из всех поводов выбирается ГЛАВНЫЙ (по порядку ниже), плюс
максимум одна строка-бонус от второго повода. Под текстом всегда строка с данными:

> +{сумма} · {клиент} · {кто} · по документу: {документ}

(документ - только если определился в момент прихода, см. «Чей это?»).

**Порядок главного повода** (сверху - важнее):
Легендарный -> Миллионник -> Без суда -> Рекорд месяца -> Должник оплатил -> Новый клиент ->
Блудный вернулся -> Эпический -> Чистый лист -> Хет-трик/покер -> Серия от клиента -> Личный
рубеж дня -> Дубль -> Редкий -> Обычный. «Время» и «Красивая сумма» - только строкой-бонусом.

**Не опознан** - всегда раздел «Чей клиент?» с кнопкой «Мой клиент» (сумма-уровень - бонусом:
«И это эпический платёж!»).

**Правила:**
- одна и та же заготовка не повторяется у одного менеджера подряд (помним последние 5);
- только плюсы - никаких сравнений менеджеров в минус (Влад 29.08: без оценочных слов);
- каждый платёж - сразу, в любое время суток, ничего не копим (Влад 24.09);
- свои компании и поставщики в группу «Поступления» не пишутся вообще.

**Подстановки** (склонение и род берутся из Справочников - один раз заполнить по каждому
менеджеру, проверит Влад):
