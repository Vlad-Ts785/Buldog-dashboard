# Интеграция с личным кабинетом Автодора (платные дороги)

Влад, 05.09: хочет тянуть данные о проездах по платным дорогам из личного
кабинета Автодора (`lk.avtodor-tr.ru`) - официального API нет, "по тому же
принципу как подключились к навигации" (см. `import/omnicomm-poller.js` на
VPS - логин/пароль в `.env`, тот же паттерн).

## Источник данных

Аккаунт `r.ryshchanov@yard-imperial.ru`, вход - обычный Keycloak OIDC
(`auth-lkmp.avtodor-tr.ru`), без капчи/2FA. Учётные данные - `.env` на VPS,
`AVTODOR_LOGIN`/`AVTODOR_PASSWORD`.

Экспорт транзакций (URL получен от Влада напрямую из DevTools 05.09):
```
GET https://lk.avtodor-tr.ru/api/client/bs/summary/contract-transactions
    ?format=csv&contractId=3150227&dateFrom=YYYY-MM-DD&dateTo=YYYY-MM-DD
```
`contractId=3150227` - фиксирован (единственный договор компании).

**Формат CSV** (пример - `contract-transactions.csv`, 01.09-05.09.2026):
```
Дата;ПВП\РВП выезда;Полоса;Электронное средство;Класс;Сумма тарифа, ₽;Скидка, %;Оплачено, ₽
```
- Одна строка = один проезд ЧЕРЕЗ ОДИН ПУНКТ трассы, не рейс целиком (один
  реальный рейс = несколько строк подряд, по числу пунктов на маршруте).
- Машина идентифицируется ТОЛЬКО номером транспондера ("Электронное
  средство"), гос.номера в файле нет.
- Числа - русский формат (`1 260,00`), даты `ДД.ММ.ГГГГ ЧЧ:ММ:СС`.
- Уникального ID транзакции нет - для перезаливки использовать
  `atomicReload()` (полная замена окна, как `import-receipts.js`), не
  инкрементальный upsert по составному ключу.
