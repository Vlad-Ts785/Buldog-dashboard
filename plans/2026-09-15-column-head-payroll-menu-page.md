# «Зарплата машинистов» - отдельный пункт меню у начальников автоколонн

Влад, 15.09 (продолжение [2026-09-15-dyachkov-tral-page-and-driver-salary-by-fleet.md](2026-09-15-dyachkov-tral-page-and-driver-salary-by-fleet.md)):
"Зарплату машинистов выведи в отдельное меню сбоку. И сделай интерфейс так же как у меня,
только без стоимости заявок и %. И Барыльченко так же." Затем уточнение: "Файмонвилисты
тоже у Дьячкова" - значит бакет Дьячкова = трал + файмонвиль (не только трал), у
Барыльченко без изменений - только длинномер.

## Что меняется

Блок "Зарплата машинистов", добавленный внутрь `renderMyPageVasin` в прошлом заходе (пункт
5 плана выше), переезжает в ОТДЕЛЬНЫЙ пункт сайдбара - тот же паттерн, что уже есть у
Рыщанова ("Зарплата") и руководителей коммерческих групп: скрытый по умолчанию пункт меню,
`applyRoleUI()` показывает только самому начальнику автоколонны или admin-предпросмотру
"как он". Интерфейс - клон admin-страницы "Зарплата -> По машинистам"
(`renderMachinistSalary`/детализация по клику), НЕ упрощённая версия - те же сортируемые
колонки, фильтры, клик по строке открывает полный расклад по машинам/рейсам/штрафам. Минус
две вещи: колонка "Процент" в сводной таблице и колонки "Стоимость заказа"/"Процент" в
детализации по клику - Влад просил именно "без стоимости заявок и %" (коммерческая цена
заказа - не для начальника автоколонны).

## Бакеты по сегменту (обновлено после уточнения про файмонвиль)

- Дьячков (tral): `vehicle_bucket` in `['трал', 'файмонвиль']`.
- Барыльченко (long): `vehicle_bucket` in `['длинномер']` (без изменений).

## VPS (`api/server.js`)

1. `/api/my_driver_payroll` - заменить `wantBucket` (строка) на массив `buckets`, фильтр
   `buckets.includes(r.vehicle_bucket)` вместо `===`.
2. Новый `GET /api/my_driver_payroll_detail` (`checkSession`, без `requireRole_`) - зеркало
   `/api/driver_payroll_detail`, но: (а) сам резолвит `own`/`fleet` по сессии, как
   `/api/my_driver_payroll`; (б) проверяет, что запрошенный `driver` реально в СВОЁМ наборе
   бакетов этого месяца (через `computeDriverPayroll_`) - иначе 403, не даём достать чужого
   машиниста по одному только имени; (в) **не селектит и не отдаёт `order_amount`** -
   коммерческая цена заказа не должна физически покидать сервер в эту ветку (не просто
   прятать в интерфейсе - сама сессия начальника автоколонны эти цифры не должна получать).
   Admin-предпросмотр "как Барыльченко/Дьячков" по-прежнему бьёт в обычный
   `/api/driver_payroll_detail` (admin и так вправе видеть всё) - фронт сам прячет две
   колонки для параметра предпросмотра, тут урезание не нужно (те же данные админ и так
   видит на своей странице).

## Основной репозиторий (`files/index.html`)

1. Новый пункт сайдбара `data-page="column-head-payroll"` ("Зарплата машинистов"), скрыт по
   умолчанию (`style="display:none"`), тот же паттерн, что `ryschanow-salary`/
   `commercial-head-salary` (HTML - копия по разметке, иконка та же, что у "Зарплата").
2. Новый `<div id="page-column-head-payroll">` с контейнером `#column-head-payroll-content`.
3. `PAGE_TITLES['column-head-payroll'] = 'Зарплата машинистов'`.
4. `applyRoleUI()`: `if (isColumnHeadViewer) allowedPages_.push('column-head-payroll')`;
   добавить в `personalOnlyPages` (не показывать в обычной admin-панели).
5. `showPage()`-диспетчер: `if (id === 'column-head-payroll') renderColumnHeadPayrollPage_();`
6. Новые функции (клон `loadMachinistSalaryData`/`renderMachinistSalary`, НЕ переиспользуют
   их состояние - отдельные module-переменные `chPayrollData_`/`chPayrollMonth_`/
   `chPayrollFilter_`/`chPayrollSort_`):
   - `columnHeadCurrentName_()` - ФИО текущего начальника автоколонны (self-login
     `D.logistName` или `viewAsEntry.name` при предпросмотре - тот же приём, что
     `currentCommercialHeadCfg_`).
   - `chPayrollBuckets_()` - массив бакетов по фамилии (см. выше).
   - `loadColumnHeadPayrollData_(month)` - `D.role==='admin'` -> `/driver_payroll` +
     клиентский фильтр по `chPayrollBuckets_()` (то же, что было в снесённом блоке
     renderMyPageVasin); иначе `/my_driver_payroll` (уже отфильтрован сервером).
   - `renderColumnHeadPayrollPage_()` - те же колонки, что `MACHINIST_SALARY_COLS_`, МИНУС
     `order_pct`. Фильтр-чипы - только если бакетов больше одного (у Дьячкова - Все/Тралы/
     Файмонвиль; у Барыльченко бакет один - чипов нет). Без кнопки "Выгрузить для печати"
     (не просили, экспорт добавляет отдельный риск утечки стоимости заказа через файл -
     сознательно не включаем, легко добавить позже, если понадобится).
   - `openColumnHeadPayrollDetail_(driverName)` - открывает ТОТ ЖЕ overlay
     (`#machinist-detail-overlay`, глобальный элемент вне какой-либо `.page`, уже
     переиспользуется), но зовёт `/my_driver_payroll_detail` (self-login) или
     `/driver_payroll_detail` (admin-предпросмотр), с флагом `hideCommercial=true`.
7. Рефактор детализации (`renderMachinistDetail_`/`mdRenderVeh_`/`MD_TRIP_COLS_`) - общий
   флаг `mdHideCommercial_` (module-var, выставляется в момент открытия), а не дублирование
   ~270 строк модалки: при `true` колонки "Стоимость заказа"/"Процент" убираются из
   `MD_TRIP_COLS_`-производного списка перед рендером head/body/footer, общий процент в
   шапке карточки (`overallPct`) не выводится. `openMachinistDetail_` (admin's own страница)
   выставляет флаг в `false` - её интерфейс не меняется.
8. Снести блок "5. Зарплата машинистов по своему сегменту" из `renderMyPageVasin`
   (текущие строки ~11094-11140) - переехал в отдельную страницу.

## Проверка

- Форджед `session_token` (тот же приём, что 15.09 весь день): Дьячков - сводная таблица
  без колонки "Процент", чипы Все/Тралы/Файмонвиль, файмонвиль-машинисты присутствуют;
  Барыльченко - без колонки "Процент", без чипов (один бакет), файмонвиль НЕ примешивается.
  `/api/my_driver_payroll_detail` для чужого (не своего) машиниста - 403. Обычный логист -
  403 на оба эндпоинта, как и раньше.

  "Процент" ни в таблице по машине, ни в шапке карточки; на admin-странице "Зарплата -> По
  машинистам" эти колонки остаются как были.
- `node --check` на все затронутые script-блоки.
- Личная страница Дьячкова/Барыльченко - блока "Зарплата машинистов" внутри неё больше нет,
  только новый пункт сайдбара.
