# Зарплата - полноэкранный хаб вместо попапа (11.09.2026)

## Проблема

Раздел "Зарплата" в сайдбаре открывал маленькое модальное окно (`.crm-modal`) поверх
текущей страницы - две строки-ссылки ("Зарплата коммерческого отдела" / "Зарплата
машинистов"), затемнённый фон вокруг. Влад, живьём глядя на попап и рядом показав
скриншот 1С:

> "меня категорически не устраивает как выглядит это диалоговое окно. в 1с так устроено
> есть бокое меню наджимаешь есть полный экран с выбором подразделов. Я бы также хотел.
> Дай превью"

Попап сам был построен по более ранней и менее точной просьбе Влада (2026-08-03,
"нажал кнопку зарплата... по клику уже уходим на нужный раздел, такой принцип в 1С") -
на этот раз формулировка точнее и подкреплена реальным скриншотом 1С (левое меню
категорий + полноэкранная область с разделами по клику).

## Решение

Новый канонический UI-паттерн - "Полноэкранный хаб-выбор раздела", задокументирован в
`DESIGN_SYSTEM.md` раздел 4 (утверждён Владом на превью 11.09.2026, ГОСТ 0.2: новый
паттерн -> одобрение -> запись в ГОСТ -> реализация).

Анатомия:
1. Клик по "Зарплата" в сайдбаре - обычный `showPage('sales-salary', this)`, НЕ попап.
2. Страница показывает стандартный заголовок ("Зарплата") + хаб `#salary-hub` по
   умолчанию.
3. Хаб - `.hub-sec-title` ("Разделы") + `.hub-grid` из `.hub-tile` карточек (иконка в
   цветном круге, название, описание, футер с реальным фактом + "Открыть →").
4. Клик по плитке - `chooseSalaryTarget_(tab)` прячет хаб, показывает нужную панель
   (`#salary-tab-managers` / `#salary-tab-machinists`) + ссылку "← Все разделы"
   (`.mp-ghostbtn`, `showSalaryHub_()`).
5. Повторный клик по пункту сайдбара всегда сбрасывает к хабу (без запомненного
   состояния) - реализовано в `showPage()`: `if (id === 'sales-salary') showSalaryHub_();`
   в самом конце функции (после блока `period-selector-wrap`, чтобы хаб мог его
   переопределить в 'none').
6. Существующая глубокая ссылка `openDriverSalaryFromVehicle_()` (клик по ФОТ водителя
   в "Технике") по-прежнему уходит сразу на вкладку "машинисты", минуя хаб - но теперь
   явно прячет `#salary-hub` и показывает `#salary-back-link` (раньше это было не нужно,
   попап не оставлял постоянного состояния поверх страницы).

## Затронутые файлы

- `files/index.html`:
  - CSS: `.hub-sec-title`/`.hub-grid`/`.hub-tile`(+`__icon`,`__name`,`__sub`,`__foot`,`__go`)
    после `.mp-ghostbtn:hover`.
  - HTML: `#salary-picker-overlay` (модал) заменён на `#salary-hub` (2 плитки) +
    `#salary-back-link`; `#salary-tab-managers` теперь стартует скрытым.
  - JS: `openSalaryPicker`/`closeSalaryPicker` удалены (ссылались на удалённый DOM-узел);
    `chooseSalaryTarget_(tab)` переписана (прячет хаб/показывает back-link, не закрывает
    попап); новая `showSalaryHub_()`; `openDriverSalaryFromVehicle_()` дополнена
    hub/back-link-переключением; `showPage()` сбрасывает к хабу при каждом заходе на
    `sales-salary`.
  - Сайдбар: `onclick="openSalaryPicker(this)"` -> `onclick="showPage('sales-salary',this)"`.
- `DESIGN_SYSTEM.md`: раздел 4, новый паттерн "Полноэкранный хаб-выбор раздела".

## Проверка

- Превью-артефакт (до/после) одобрен Владом ("Да не плохо делай") до реализации.
- Синтаксис: все 3 реальных `<script>`-блока (калькулятор, основной ~18.6К строк,
  Планировка) - `node --check`, 0 ошибок.
- Функционально (Browser pane, локальный `serve` на `files/`, прямые вызовы функций):
  - Заход на страницу - хаб виден, back-link и обе панели скрыты, period-selector скрыт.
  - Клик по плитке "коммерческий отдел" - хаб скрыт, back-link виден, нужная панель
    видна, заголовок "Зарплата - коммерческий отдел".
  - Клик "← Все разделы" - обратно к хабу, заголовок "Зарплата", period-selector скрыт.
  - Повторный клик по пункту сайдбара после открытой панели - сброс к хабу (без
    запомненного состояния, как задумано).
  - `openDriverSalaryFromVehicle_()` (глубокая ссылка) - хаб скрыт, back-link виден,
    сразу открыта вкладка "машинисты", минуя хаб.
  - Визуально - хаб рендерится с 2 плитками, иконками и сеткой, как в одобренном превью.

## Что не входит в эту итерацию

- Группировка разделов (`.hub-sec-title` пока одна группа "Разделы") - если появится
  третий раздел, разбивать на смысловые группы по образцу 1С.
