# Ретроспектива: светофор контрагентов (Checko) от идеи до автомата + кастомизация меню

**Сессия:** 04-05.09.2026, вечер-ночь, ветка `claude/yard-hub-interface-architecture-39c456`.
**Формат:** Влад ставил задачи короткими сообщениями по мере того, как видел результат на
экране; последняя ("кастомизация меню... сделай всё сам") - перед сном, без обратной связи.

## Что сделано (по порядку запросов)

1. **Шапка Планировки вчера/сегодня/завтра** - дизайн-штурм из 3 вариантов, Влад выбрал
   "триплет" без спарклайнов; формула "сегодня" не тронута, для соседних дней тот же
   алгоритм с h±24; вспышка на "Заказов" при чужом новом заказе.
2. **Светофор риска контрагентов** - исследование рынка (Checko.ru, бесплатный тариф с API),
   прозрачная формула из флагов ЕГРЮЛ вместо чужого скоринга, кэш на юрлице, кнопка в
   карточке, точка в списке; два бага в первый час живого использования (`req.body` vs
   `req.query`; `updated_at` ломал optimistic locking "Сохранить").
3. **Лампочка в ДЗ** - сопоставление должник->юрлицо по имени (4 ступени), партия по
   корзинам просрочки, затем "логика везде" - все 5 мест вывода контрагента.
4. **Пороги по итогам прогона** (недоимка < 100 тыс. и санкции -> жёлтый, массовый адрес не
   влияет) + `risk_raw` и пересчёт без квоты; корзины 31-90 дн.
5. **Автопрогон** - cron 06:10 МСК, приоритеты по срокам годности корзин, три ключа Checko
   с ротацией (300/день), журнал прогонов; день квоты у Checko - по Москве.
6. **Череп для банкротов** - четвёртое состояние по официальному статусу ЕГРЮЛ.
7. **Кастомизация меню сайдбара** - долгое нажатие -> режим (ГОСТ разд. 6), drag&drop с
   FLIP, скрытие, плашка "Готово", сервер `menu_configs`, ключ `admin|role:фамилия`,
   admin настраивает меню сотруднику через "Смотреть как".

## Что сработало

- **Живая диагностика раньше кода** - каждый спорный факт проверялся curl'ом (бесплатный
  тариф Checko даёт API? структура ответа? день квоты? имя метода арбитража?), а не
  предполагался. Все четыре раза память/обзоры расходились с реальностью хотя бы в детали.
- **Клонировать паттерн, не изобретать** - меню взяло физику и жест из ГОСТа и Планировки,
  числа буквально; ни одного нового "дизайнерского" решения, кроме уже описанных.
- **Гвард md5/HEAD перед каждой заливкой server.js** - параллельные сессии в тот же вечер
  коммитили туда; ни одного тихого отката.
- **Smoke-тест в Browser pane без логина** - stub `D.role`, показать сайдбар, спрятать
  оверлеи: за 4 итерации проверены вход/выход/скрытие/drag/Esc, найдена ловушка координат.

## Что не сработало / уроки

- **Два бага сразу после деплоя светофора** - оба класса "не сверился с соседним кодом"
  (`postToYardApi_` шлёт query-строкой; `ON UPDATE CURRENT_TIMESTAMP` на `updated_at`). Мой
  curl-тест не ловил первый, потому что я сам знал правильный формат - тест "проверял
  себя". Урок записан в DEPLOY_LOG и память: новый эндпоинт под существующий хелпер -
  сначала посмотреть соседний эндпоинт того же хелпера.
- **Формула светофора первого захода была слишком строгой** (8 502 ₽ недоимки = красный,
  санкции = красный) - правильно, что вынес на решение Владу вместо тихой подгонки, и
  правильно, что заранее сохранил `risk_raw` - пересчёт без квоты занял секунду.
- **Browser pane:** `file://` не открывается, координаты - в кадре скриншота. Записано в
  память, чтобы не терять заход в следующий раз.
- **MEMORY.md подошёл к лимиту** (19.8 KB) - сжат в конце сессии.

## Открытые хвосты (в памяти и DEPLOY_LOG)

- 8 должников не сопоставляются с юрлицом (филиалы "ДиМ" с общим ИНН, КРОКУС, НВЛ, ЛЕГРАН)
  - лечится ИНН в названии в 1С.
- "АЛМАЗ ООО" 754 млн ₽ и "МОСПРОЕКТ-3" 489 млн ₽ недоимки - похоже на артефакт Checko.
- Арбитраж (`/v2/legal-cases`) есть в API, не подключён - удваивает расход квоты.
- Меню: автопрокрутка при драге, тач-сценарий первого drag из долгого нажатия.
- Три бесплатных аккаунта Checko - риск блокировки, решение Влада, код это переживёт.
