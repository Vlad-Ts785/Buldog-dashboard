# Перенос показа сайта с GitHub Pages на свой VPS + приватный репозиторий

**Статус:** в работе
**Одобрено:** Влад, 2026-09-13 - продолжение разговора про защиту кода от кражи. Цель - убрать
GitHub как публичную витрину (историю коммитов, Apps Script, документы, планы), при этом не
уронить `yardhub.ru`, которым пользуется вся компания каждый день. Правило сессии - "мягкая
посадка": на боевой домен переключаемся только после того, как всё проверено в обход него.

## Разведка (сделана 13.09, до написания плана)

- **DNS `yardhub.ru`** сейчас указывает на IP-адреса GitHub Pages (`185.199.108/109/110/111.153`),
  отдельного стороннего CDN/прокси перед сайтом нет - кэш 10 минут из CLAUDE.md это встроенный
  CDN самого GitHub Pages (Fastly), не что-то дополнительное.
- **SSL-сертификат** сейчас автоматически выпускает и продлевает GitHub (Let's Encrypt).
- **DNS домена управляется через Beget** (`ns1/ns2.beget.ru`) - тот же провайдер, что держит VPS,
  менять A-запись предстоит в той же панели.
- **На VPS уже стоит и работает Nginx** (слушает 80/443, судя по всему проксирует `api.yardhub.ru`)
  - не нужно ничего ставить с нуля, только добавить новый server-блок.
- **Ресурсы VPS с большим запасом**: 2 CPU (загрузка 0.01-0.05), 3.8 ГБ RAM (2.7 ГБ свободно/в
  кэше), 24 ГБ свободного диска из 38 ГБ. Отдача статики - на порядок легче того, что сервер уже
  держит (MySQL, Node API, cron-импорты).
- **Что реально нужно копировать на сервер** (проверено по факту в репозитории, не по памяти):
  корневой `index.html` (редирект на `files/index.html`), `CNAME`, `.well-known/assetlinks.json`
  (проверка Android-приложения), и весь `files/` - `index.html`, `app.html`, `driver.html`,
  `plan-m.html` + их `*.webmanifest`, `sw.js` (service worker - PWA), `logo.png`, `icon-192.png`,
  `icon-512.png`, `manifest.json`, `order-plan-v2.css`/`.js`, `tshub.apk`. Это больше, чем один
  дашборд - есть мобильные страницы и Android-приложение, все должны переехать вместе.

### Фаза 2. SSL-сертификат ДО переключения DNS (нулевой простой) - ГОТОВО 13.09
- [x] Получен сертификат Let's Encrypt для `yardhub.ru` через `certbot --manual

      задержка распространения), вторая попытка после подтверждённого расхождения (`dig` с

- [x] Влад добавил TXT-запись `_acme-challenge.yardhub.ru` в панели Beget (дважды - второй
      раз со свежим токеном после первой неудачной попытки).
- [x] Nginx настроен на `server_name yardhub.ru` с этим сертификатом (HTTPS 443 + редирект с
      80), проверено `curl`/`openssl` по IP с поддельным Host/SNI - домен ещё указывает на
      GitHub, реального трафика через новый сервер пока нет.
- [ ] **ВАЖНО, не забыть**: certbot предупредил - это НЕ автопродлеваемый сертификат (нужен

## Что сознательно НЕ входит в этот план

- Обфускация/минификация клиентского JS - отдельная опциональная задача, обсуждали как низкий
  приоритет (поднимает порог для любопытного, не для решительного).
- Полный переезд самого git с GitHub на свой сервер (Gitea и т.п.) - не обязателен для достижения
  цели "код не гуляет публично", GitHub-приватности достаточно; можно рассмотреть отдельно, если
  Влад позже захочет полной независимости от GitHub как компании.
