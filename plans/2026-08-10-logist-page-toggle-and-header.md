# План: шапка ФИО+должность и переключатель «Свои продажи / Общие сделки»

**Дата:** 2026-08-10
**Автор:** Клод
**Статус:** реализовано, ждёт деплоя

## Цель

Продолжение [plans/2026-08-10-logist-personal-page.md](2026-08-10-logist-personal-page.md).
Два доработки личной страницы:
1. Шапка страницы = ФИО + должность того, кто на неё смотрит (сейчас - просто сырое имя).
2. Логисту (начиная с Прус-Роскошного) - переключатель «Свои продажи» / «Общие сделки»:
   вторая вкладка показывает всю ситуацию по направлению найма ЦЕЛИКОМ по компании, не
   только его сделки.

## Контекст

Влад, дословно: «вверху надпись нужно сделать личной страницей: фамилия, имя, отчество,
должность того, кто заходит» + «Прусу Роману нужно добавить две кнопки: «Свои продажи» и
«Общие сделки». При нажатии у него открывается страница со всеми сделками по наёмному парку,
то есть он видит абсолютно всю ситуацию по направлению».

Ограничение: патронима (отчества) в данных нет нигде (1С отдаёт только Фамилия+Имя, см.
`TRAL_LOGISTS`/`TRAL_MANAGERS` - только фамилии, полное имя приходит построчно из отчёта).
Показываем то, что реально есть - фамилию+имя (без выдумывания отчества), плюс должность
по должностной привязке (map по типу роли, с точечными исключениями для руководителей).

Ключевое техническое отличие «Общие сделки» от уже готового «Свои продажи»: нужны данные по
ВСЕЙ компании (все поставщики, все сделки найма, не только его), а урезанный ответ роли
`logist` (`getLogistView_`) сейчас отдаёт только его личные `logist_detail`/`by_logist`. Плюс
у общего `by_hired_supplier` (глобальный, уже существует) нет разбивки воронки документов по
стадиям (только `no_waybill`) - у личного `logist_detail.by_supplier` она уже есть (сделано в
прошлой итерации), нужно достроить то же самое для глобального.

## Критерии готовности

- [ ] Шапка показывает "Фамилия Имя" + должность, не сырую строку без контекста.
- [ ] «Общие сделки» у логиста показывает те же суммы, что вкладка "Наёмная техника" на
      "Обзор заказов" (сверка тотала по компании).
- [ ] «Свои продажи» не изменилась (регрессия исключена).
- [ ] Роль `logist` при реальном логине (не только admin-предпросмотр) видит обе вкладки.

## Риски

- Урезанная роль `logist` получает доступ к данным ВСЕЙ компании по направлению найма (не
  только своим) - осознанное решение Влада ("видит абсолютно всю ситуацию по направлению"),
  но стоит явно подтвердить, что это не должно быть доступно остальным логистам без разбора
  (сейчас распространяется на любого с ролью `logist` в листе "Доступ", не только на Прус).
