# Поле "Отдел" на материальном средстве (Справочники) - замена хардкод-списка исключений

## Контекст

01.09.2026 машины У 589 ОХ 750 / У 660 ОХ 750 временно переданы в отдел экскаваторов -
реализовано быстрым хардкод-списком `EXCLUDED_VEHICLE_GOS` (Apps Script) +
`EXCLUDED_VEHICLE_GOS_SERVER_` (VPS), см. `scripts/DEPLOY_LOG.md` 01.09 и память
`project_vehicles_temporarily_excluded_from_calcs`. Работает, но два списка нужно синхронно
править руками при каждом изменении, и любое изменение требует деплоя кода.

Влад предложил лучший подход: поле "отдел" прямо на материальном средстве в Справочниках
(`sprav_assets`), по умолчанию "Тралы" у всего, что есть сейчас; переключается вручную в
UI; все расчёты дашборда читают это поле, а не список госномеров в коде.

## v1 (сделать сейчас)

1. **Схема** - `sprav_assets.department` VARCHAR(30) NULL, трактуется как "Тралы" если
   NULL/пусто (обратная совместимость со старыми строками без миграции данных). Явно
   выставить у трёх уже известных исключённых машин: А 840 КО 797 → `в аресте`,
   У 589 ОХ 750 / У 660 ОХ 750 → `экскаваторы`. Остальное остаётся NULL = Тралы.

2. **Сервер (`api/server.js`)**:
   - `/api/park_summary`, `/api/park_history` - JOIN `sprav_assets` по `id = gos_number`,
     исключать строки где `department IS NOT NULL AND department != ''`. Хардкод-список
     `EXCLUDED_VEHICLE_GOS_SERVER_` убрать целиком - заменяется полем.
   - `/api/sprav/state` - отдавать `department` в списке материальных средств.
   - Эндпоинт создания/правки актива - принимать `department` в теле запроса.
   - Новый `GET /api/vehicle_departments` (checkServerKey, как `/api/vehicle_drivers`) -
     отдаёт `{gos: department}` только для НЕ-тралы машин (обычно 1-3 строки).

3. **Apps Script (`scripts/full_script_final.js`)**:
   - `getStaffData()`/`aggregateFinHistoryForRange()` - вместо статического
     `EXCLUDED_VEHICLE_GOS` спрашивают `/api/vehicle_departments` (тот же приём, что
     `fetchVehicleDriversFromServer_`), исключают госномера с непустым отделом. Тихий
     фолбэк на СТАРЫЙ статический список при недоступности сервера (защита, не убирать
     совсем - тот же принцип "мягкого перехода", что и у водителя по машине).

4. **Фронтенд (`files/index.html`, Справочники → Материальные средства)**:
   - Колонка "Отдел" в таблице (пусто/"Тралы" по умолчанию).
   - В форме правки актива - выпадающий список (Тралы / Экскаваторы / В аресте / + сохранить
     возможность ввести другое значение текстом, если появится третий отдел, которого нет в
     списке - не блокировать Влада, если ему понадобится сегодня добавить ещё один).

## Не в v1 (сознательно отложено)

- Отдельные "виды" дашборда per-отдел (например переключаемая вкладка "Экскаваторы" со
  своей аналитикой) - сейчас нужно только "исключить из Тралов", не построить параллельную
  систему учёта экскаваторов.
- Массовое перемещение множества машин разом - форма правки одной машины за раз достаточно
  для текущего объёма (единицы машин).

## Проверка перед сдачей

- Обе КАМАЗа пропадают из Техники/Планировки/Валовой прибыли ПОСЛЕ смены поля через UI, без
  деплоя кода.
- Возврат машины обратно (Тралы) через UI - появляется в расчётах текущего периода, без
  восстановления истории (её и не трогали).
- Сверка сумм Валовой прибыли до/после миграции с хардкод-списка на поле - те же цифры
  (не должно быть регресса из-за смены механизма фильтрации).
